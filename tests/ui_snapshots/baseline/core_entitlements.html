Groups and Access

Put people (or AI assistants) into groups, then give each group a ready-made access package . Each package explains in plain words what it allows and what it does not.

#. Groups

People groups hold your staff (picked from your user list). AI assistants and integrations groups hold API keys (shown by label only) and can never receive high-governance packages.
